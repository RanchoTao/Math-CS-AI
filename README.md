# Math · CS · AI Atlas

一个面向纯数学、计算机科学与人工智能的多尺度知识图谱。

网站不是把学校课程表直接画成树，而是区分四层：

1. **Knowledge Node**：相对稳定的知识模块；
2. **Course Offering**：不同学校和平台对知识模块的课程实现；
3. **Curriculum Layer**：某个专业培养方案选择并组织了哪些节点；
4. **Personal Route**：个人希望把各节点掌握到什么深度。

- L0–L8 学习阶段筛选；
- 公共图谱、共同核心、个人研究主线三种图层；
- 大语言模型、系统研究、现代纯数学、数字生命四条示例路线；
- 全局搜索、依赖跳转、节点详情、平移与缩放。

## 设计原则

- 数学、计算机和 AI 是依赖图，而不是严格的单棵树；
- 层级表示大致学习阶段，不等同于难度或学科高低；
- Python、React、PyTorch 等具体工具不替代稳定知识节点；
- 跨领域共用一个知识节点，例如线性代数不会复制成数学版和 AI 版；
- 全局图显示学科群，进入局部图后再显示课程级节点，避免数百节点同时堆叠。

## 本地运行

```bash
python -m http.server 8000
```

打开 `http://localhost:8000`。
