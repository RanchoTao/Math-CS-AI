# 机器学习

## 课程简介
研究如何从数据中拟合可泛化的模型，覆盖监督学习、无监督学习、评估和正则化。

## 为什么学习
它提供将统计假设转化为预测系统的框架，也是深度学习和现代 AI 应用的基础。

## 前置知识
- 线性代数、概率论、微积分；推荐掌握最优化与 Python。

## 课程大纲
1. 学习问题、损失函数与数据划分
2. 线性模型、梯度方法与正则化
3. 树模型、集成学习与核方法
4. 聚类、降维与概率模型
5. 泛化、模型选择、公平性与可复现性

## 推荐教材
- Christopher Bishop, *Pattern Recognition and Machine Learning*
- Murphy, *Probabilistic Machine Learning: An Introduction*

## 练习与项目
从零实现线性/逻辑回归；比较交叉验证策略；在真实数据集上撰写模型卡。

## 最低完成标准
能建立无泄漏的训练流程，解释偏差—方差权衡，并复现实验与误差分析。

## 后续课程
深度学习、强化学习、计算机视觉、自然语言处理。
