# 数据结构

## 课程简介
学习数组、链表、树、图与哈希表，理解数据布局如何决定程序效率。

## 为什么学习
选择合适的数据结构是算法设计与可靠软件的基础，也为系统课程建立复杂度直觉。

## 前置知识
- 熟悉 Python 或 C++；离散数学可同步学习。

## 课程大纲
1. 渐近分析与抽象数据类型
2. 线性表、栈、队列
3. 哈希表、集合与字典
4. 树、堆与平衡搜索树
5. 图的表示、遍历与并查集

## 推荐教材
- Cormen 等，*Introduction to Algorithms*（相关章节）
- Sedgewick & Wayne, *Algorithms*

## 练习与项目
实现动态数组和哈希表；比较不同负载因子的性能；构建支持路径查询的小型图工具。

## 最低完成标准
能从零实现至少六种结构，说明操作复杂度，并用测试验证边界条件。

## 后续课程
算法设计、操作系统、数据库、编译原理。
