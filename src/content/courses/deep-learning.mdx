# 深度学习

## 课程简介
学习神经网络的表示、优化与泛化，从多层感知机延伸到卷积网络和注意力机制。

## 为什么学习
深度学习驱动视觉、语言和生成模型；理解训练机制比调用框架 API 更重要。

## 前置知识
- 机器学习、线性代数、概率论、微积分与 Python。

## 课程大纲
1. 计算图、反向传播与初始化
2. 优化器、归一化、正则化
3. 卷积网络与视觉表示
4. 序列建模、注意力与 Transformer
5. 生成建模、缩放规律与部署基础

## 推荐教材
- Goodfellow, Bengio & Courville, *Deep Learning*
- Simon Prince, *Understanding Deep Learning*

## 练习与项目
手写自动微分核心；训练并诊断图像分类器；完成包含消融实验的复现报告。

## 最低完成标准
能推导反向传播、诊断欠拟合和过拟合，并交付一个可复现的端到端训练项目。

## 后续课程
计算机视觉、自然语言处理、生成模型、Transformer、AI 系统。
