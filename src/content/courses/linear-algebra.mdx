# 线性代数

## 课程简介
从向量空间出发，理解矩阵、线性变换、特征值与分解。重点不是机械消元，而是用结构化语言描述高维问题。

## 为什么学习
线性代数连接几何、数值计算和机器学习；数据表示、最小二乘和神经网络都建立在它之上。

## 前置知识
- 高中代数与函数；基础 Python（可选）。

## 课程大纲
1. 线性方程组、消元与矩阵
2. 向量空间、基、维数和线性映射
3. 行列式、特征值与对角化
4. 内积、正交投影与最小二乘
5. SVD 与数值视角

## 推荐教材
- Gilbert Strang, *Introduction to Linear Algebra*
- Sheldon Axler, *Linear Algebra Done Right*

## 练习与项目
证明秩—零化度定理；不用现成回归函数实现最小二乘；用 SVD 压缩一幅图像。

## 最低完成标准
能解释基变换与线性映射，独立完成消元、投影、特征值和 SVD 基础题，并提交一个数值项目。

## 后续课程
数值分析、最优化、机器学习、深度学习。
